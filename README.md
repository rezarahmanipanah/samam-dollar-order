# دستور خرید دلار سمام

برنامه مستقل و آفلاین محاسبه خرید دلار و ساخت دو رسید جداگانه برای صراف و صاحب سرمایه.

## انتشار رایگان روی GitHub Pages
در مخزن، به **Settings → Pages** بروید. زیر **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید. شاخه **main** و پوشه **/(root)** را انتخاب و **Save** کنید.

نشانی برنامه پس از فعال‌شدن GitHub Pages:
https://rezarahmanipanah.github.io/samam-dollar-order/

## نصب روی آیفون
نشانی بالا را در **Safari** باز کنید. سپس از **Share → Add to Home Screen → Add** استفاده کنید. بعد از اجرای اولیه و ذخیره فایل‌ها، قابلیت محاسبه و تولید رسید بدون اینترنت نیز کار می‌کند.

## حریم خصوصی
محاسبات و تولید رسید داخل مرورگر انجام می‌شود. اطلاعات واردشده برای این محاسبات به سروری ارسال نمی‌شود. کد برنامه و فایل‌های آن در مخزن عمومی قابل مشاهده هستند.
